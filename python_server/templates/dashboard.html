Plain English

Each tab is one isolated $1000 practice book. Finder only lists tokens — it does not size trades.

Cluster — Gecko new pools with enough unique buyers, 5-minute hold and trail.
Sniper — Pump.fun creates; scratch book with a faster exit for comparison.
Hold — same Pump tape as sniper, cluster-style 5-minute trail.
Launch — young Gecko pools before a full cluster forms (lives in the cluster book).
Arb — same coin priced differently in two places; paper buy-cheap / sell-rich.
Scalp — forecast buy/sell on Finder tokens. Pause auto-trader lives on this tab.
Finder — token hunt board. Active hunt can be traded by scalp; watch-only is paused or cooling down.
Reset board — archive logs and start every book from $1000 again.
